# ☕ 20 Java If / Else Exercises — Interactive Web App

A clean, modern, and simple interactive website created to fulfill all requirements from the **"20 If / Else Exercises — Java"** practice sheet.

---

## 🌟 Features

1. **All 20 Exercises Implemented**:
   - **Level 1 — Basic**: Exercises 1 to 5
   - **Level 2 — if / else if / else**: Exercises 6 to 10
   - **Level 3 — Multiple Conditions (`&&` / `||`)**: Exercises 11 to 15
   - **Level 4 — Analytical Problems**: Exercises 16 to 20

2. **Interactive Live Testing**:
   - Each exercise has clean input boxes, default sample values, and a **"Check Result"** button.
   - Outputs are color-coded (Green for Pass/Success, Red for Fail/Warning, Blue for Info).

3. **Expandable Java Code & Syntax**:
   - Click **"View Java Code"** on any exercise card to see the exact Java syntax and condition logic.

4. **Level Filter & Instant Search**:
   - Filter by Level using quick buttons.
   - Search by keyword (e.g., `discount`, `password`, `scholarship`) to jump to any exercise.

5. **Ready-to-Run Java File (`AllExercises.java`)**:
   - Includes full Java source code with all 20 exercise methods ready to compile and run.
