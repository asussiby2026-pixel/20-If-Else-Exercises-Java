#16 Analytical

Parking Fee

1st hour = Rp5,000, each additional hour = Rp3,000, maximum fee = Rp20,000. Example: 5 hours = Rp17,000.

Click button to test 
int hours = 5;
int fee = 0;

if (hours <= 0) {
    fee = 0;
} else if (hours == 1) {
    fee = 5000;
} else {
    fee = 5000 + (hours - 1) * 3000;
    if (fee > 20000) {
        fee = 20000; // Capped at max fee
    }
}
System.out.println("Parking Fee: Rp " + fee);

#18 Analytical

Cashier Program

Members receive 10% discount. Checks if payment is sufficient, then calculates the final amount and change.

Click button to test 
double totalPurchase = 200000;
double payment = 200000;
boolean isMember = true;

double finalAmount = totalPurchase;
if (isMember) {
    finalAmount = totalPurchase * 0.90; // 10% off
}

if (payment < finalAmount) {
    System.out.println("Insufficient payment");
} else {
    double change = payment - finalAmount;
    System.out.println("Final: Rp " + finalAmount);
    System.out.println("Change: Rp " + change);
}
